# Saharat Labs — Community Hub

ยินดีต้อนรับ! ที่นี่คือพื้นที่พูดคุย แลกเปลี่ยนไอเดีย และประกาศของ **Saharat Labs**

## 💬 เริ่มต้นใช้งาน

- เปิด [Discussions](../../discussions) เพื่อดูหัวข้อทั้งหมด
- ยังไม่รู้จะเริ่มตรงไหน? ตั้งกระทู้แนะนำตัวที่หมวด **General** ได้เลย

## 🗂️ หมวด Discussions

| หมวด | ใช้สำหรับ |
|---|---|
| 📣 Announcements | ประกาศข่าวสาร / อัปเดตจากทีม |
| 💬 General | คุยทั่วไป แนะนำตัว |
| 💡 Ideas | เสนอไอเดีย / ฟีเจอร์ใหม่ |
| 🙏 Q&A | ถาม-ตอบ (เลือกคำตอบที่ถูกต้องได้) |
| 🙌 Show and tell | โชว์ผลงาน / โปรเจกต์ |
| 🗳️ Polls | โหวตความเห็น |

## 🚀 โปรเจกต์ของเรา

- ดูรายการโปรเจกต์ทั้งหมดได้ที่ **[all-in-one](https://zetxero-ceo.github.io/all-in-one/)**
